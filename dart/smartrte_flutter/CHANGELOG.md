# Changelog

## 0.2.0

- Add reliable checklist, bullet, alphabetic, numeric, and Roman list controls.
- Apply list formatting to every selected line, including the final selection endpoint.
- Preserve and convert list items consistently across list styles.
- Support blockquotes and code blocks within list workflows.
- Improve heading and font-size behavior, including removal of explicit sizes when applying headings.
- Add left, center, right, and justified alignment for paragraphs, headings, lists, code blocks, and table cells.
- Redesign link insertion and editing with display text, destination validation, removal, opening, and secure new-tab behavior.
- Improve editor toolbar responsiveness and synchronize the embedded editor bundle with the React editor.

## 0.1.2

- Improve image context menu: link, target, radius, replace, reset
- Better drag-and-drop for images
- Minor UI polish to toolbar icons
